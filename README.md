# Merry Christmas — аркада-жонглирование Дедами Морозами

Браузерная аркада: мышью двигаете палку и подбиваете падающих пьяных Дедов
Морозов. Каждый удар отрезвляет, протрезвевший улетает и освобождает место.
Режим бесконечный, до потери всех HP.

## Запуск

Два способа, оба рабочих:

- **`start.bat`** — рекомендуется. Игра открывается через локальный сервер, и
  рекорды автоматически пишутся в `records.js` рядом с `index.html`. Файл
  переезжает вместе с папкой. Нужен Python.
- **двойной клик по `index.html`** — без сервера и интернета. Рекорды
  сохраняются автоматически, но в браузер, а не в файл: при переносе папки на
  другую машину они не поедут.

Так вышло не по лени: страница, открытая по `file://`, не может записать файл
на диск — это запрет браузера, обойти его из кода нельзя. Если рядом уже лежит
`records.js`, игра подхватит его в обоих режимах.

## Управление

| | |
|---|---|
| мышь | двигает палку по горизонтали |
| пробел | пауза |
| `Esc` | выйти в меню |
| `R` | рестарт на экране проигрыша |
| `M` | звук вкл/выкл (или клик по надписи в углу) |

Бант в центре палки — сладкая зона: даёт вдвое больше трезвости и самый
высокий отскок. Но целиться в него дольше, а времени не всегда хватает.

Смещение точки удара от центра палки задаёт, куда Дед Мороз улетит и когда
вернётся. Это главный инструмент: телами можно управлять, сгоняя их к центру
и разводя по времени, чтобы они не падали одновременно.

## Состав

```
index.html          разметка и стили
config.js           ВСЕ числовые параметры игры
game.js             логика и отрисовка
start.bat           запуск с автосохранением рекордов в файл
server.py           локальный сервер: отдаёт папку, пишет records.js
records.js          рекорды; появляется сам после первого забега
assets/             спрайты, спрайтшиты, фон
assets/audio/       звук и музыка
BALANCE.md          анализ баланса: откуда взялись цифры
assets/raw/         исходники до обработки — в поставке не нужны (~40 МБ)
tools/              инструменты разработки — в поставке не нужны
```

Игра целиком — 1.3 МБ. Достаточно `index.html`, `config.js`, `game.js` и
`assets/` без подпапки `raw`.

Настройка баланса — только `config.js`. Ничего больше править не нужно.

## Инструменты

```
node tools/sim.js 300        симулятор баланса: 3 пресета × 4 уровня скилла
node tools/tune.js 40        развёртка параметров под целевую кривую
python tools/sound.py        пересобрать звук и музыку
python tools/postprocess.py  ключевание фона и ресайз спрайтов из assets/raw
python tools/anim.py ...     сборка спрайтшита из кадров видеомодели
```

Отладочные режимы игры:

```
index.html?demo=normal&ff=90   запустить забег и прокрутить 90 секунд ботом
index.html?perf=1              замер кадра при 15 объектах, результат в <title>
index.html?click=450,213       синтетический клик в логическую точку
index.html?key=Escape          синтетическое нажатие клавиши
```

Последние два пишут итог в `document.title` — так проверяются кнопки и
горячие клавиши без живой мыши.

## Как делались ассеты

Графика — Gemini через `agy` (`tools/gen.ps1`), мультяшный стиль с толстым
контуром на magenta-фоне, дальше `postprocess.py` выбивает фон в альфу с
подавлением фиолетовой каймы и режет по содержимому. Варианты цвета носа —
img2img правкой исходного спрайта, поэтому персонаж во всех состояниях один и
тот же. Уголь пришлось делать через ComfyUI/SDXL, когда кончилась квота API.

Анимация — ComfyUI + WAN 2.2 TI2V-5B: из готового спрайта короткий ролик,
дальше `anim.py` нормирует кадры по центроиде и площади силуэта (иначе
видеомодель «дышит» масштабом) и склеивает спрайтшит.

Звук синтезирован офлайн (`sound.py`), сторонних сэмплов нет. Музыка — «Jingle
Bells» (1857), общественное достояние.
